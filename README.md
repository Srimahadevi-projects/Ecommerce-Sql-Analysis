E Commerce Data Analysis using SQL Server
 Overview
This project analyzes e-commerce sales, customers, sellers, payments, and delivery performance using SQL Server.
 Techniques Used
•	Joins, Aggregates, CTEs, Subqueries
•	Views & Window Functions
•	Indexes, Primary & Foreign Keys
 Analysis Highlights
•	Revenue & Monthly Sales Trends
•	Top Sellers & Product Categories
•	Delivery Delay Impact
•	Customer Retention & Payment Preferences
 Key Insights
•	Most customers placed only one order
•	Few sellers contributed majority of revenue
•	Delivery delays reduced satisfaction
•	Seasonal sales patterns observed
 Deliverables
•	Database Script: E_commerce_Database.sql
•	Project Report: Ecommerce-Project-Report.docx
